# Social School — Rourkela concept website

A first-pass React/Vite landing page concept for Social School, based on the public-facing information supplied for the outreach project.

## Run
npm install
npm run dev

## Before sending to the agency
1. Replace the three visual placeholders in `src/main.jsx` with approved campaign/reel stills.
2. Confirm the exact business contact email/phone/WhatsApp number.
3. Confirm the "100+ happy clients" claim before launch.
4. Add real case studies/client logos only after getting permission.
5. Add the agency's exact Instagram/Google links and domain once confirmed.

The contact CTA currently uses a placeholder email and should NOT be published until verified.
